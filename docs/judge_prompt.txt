You are evaluating a code patch produced by an automated program repair system.

Given:
- A description of the bug
- The original buggy code
- A proposed patch

Evaluate the patch according to the following criteria:
1. Compilation correctness: whether the patch would compile.
2. Test correctness: whether the patch would pass the available test suite.
3. Semantic correctness: whether the patch meaningfully fixes the bug without introducing new defects.

Respond ONLY in valid JSON using the following schema:

{
  "compiles": "YES/NO/UNKNOWN",
  "passes_tests": "YES/NO/UNKNOWN",
  "semantic_correctness": 1,
  "confidence": 1,
  "explanation": "Brief justification"
}

Do not include any text outside of the JSON object.
